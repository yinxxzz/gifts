# 赠品策略图文包上传说明

同事不需要操作 Git 或服务器。把 Cursor 生成的 ZIP 上传到赠品策略页即可。

## 怎么上传

1. 打开赠品策略网站。
2. 点击顶部“上传图文包”。
3. 选择或拖入 ZIP 文件。
4. 核对期次、礼包数、赠品数和图片数。
5. 点击“确认上传”。

同一个期次 ID 会更新该期次；新的期次 ID 会新增到下拉列表。其他期次不会被清空。

## ZIP 结构

```text
赠品图文包.zip
├── periods.json
└── assets/
    └── YYYY-MM/
        └── 赠品名称/
            ├── 赠品名称-01.jpg
            └── 赠品名称-02.jpg
```

ZIP 外面多套一层文件夹也可以，网站会自动找到 `periods.json` 和 `assets/`。

`periods.json` 可以是：

```json
{
  "periods": [
    {
      "id": "2026-10",
      "title": "10月系统课加赠",
      "subtitle": "2026-09-24 ~ 2026-10-23",
      "status": "upcoming",
      "statusLabel": "即将上线",
      "summary": "本期策略介绍",
      "bundles": [
        {
          "id": "bundle-1",
          "name": "主礼包",
          "rule": "4选1",
          "recommended": [],
          "gifts": []
        }
      ]
    }
  ]
}
```

也可以使用单个期次对象并命名为 `period.json`。

## 上传后修改

- 页面文字三击后可以直接编辑，失焦后自动保存。
- 期次状态和赠品上架状态也会保存为全员共享内容。
- 页面每 15 秒检查一次更新，其他同事不需要重新部署。
