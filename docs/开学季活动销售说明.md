# 开学季特别活动销售说明

## 1. 活动是什么

8月26日到9月8日，用户下单系统课后，**9月常规加赠照常享有**，同时额外获得开学季专属抽奖机会。

抽奖是 **3抽N，100% 抽中实物**，N 按下单科目数计算，奖品为：

- 斑马书包
- 美术大礼包
- 多功能升降阅读架

如果用户购买的是**英语系统课**，还会额外赠送《成为最强大脑》1本。

## 2. 活动时间

**2026-08-26 ~ 2026-09-08**

## 3. 销售使用提醒

这个活动是销售促单抓手，不要求每次都必须主动讲。  
如果下单前跟家长提到了开学季抽奖，用户下单后就要把固定抽奖链接发给家长。

抽奖链接后续补充。

## 5. 常见问题

**Q：开学季抽奖和9月常规赠品冲突吗？**  
不冲突。9月常规赠品照常享有，开学季抽奖是额外多一次。

**Q：所有学科都能参加抽奖吗？**  
可以，活动期内下单系统课都能参加开学季抽奖。

**Q：英语系统课有什么额外福利？**  
购买英语系统课，除了开学季抽奖，还额外赠送《成为最强大脑》1本。

**Q：抽奖能自己选奖品吗？**  
不能自选，3个实物里按下单科目数随机中对应数量，100%中奖。

**Q：抽奖链接在哪里？**  
固定链接后续补充。销售如果下单前提到了活动，下单后记得把链接发给家长。
